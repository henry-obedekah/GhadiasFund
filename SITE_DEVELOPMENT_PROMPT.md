# 🌍 GHADIAS Investment Fund - Prompt de Développement du Site Web

## 📋 CONTEXTE GÉNÉRAL

GHADIAS Investment Fund Limited est une entreprise d'investissement basée au Ghana qui mobilise le capital de la diaspora pour investir dans les secteurs clés du Ghana. Le site doit servir de plateforme centrale pour :
- Présenter la vision et les opportunités d'investissement
- Attirer les investisseurs de la diaspora
- Fournir des informations transparentes sur les fonds et les projets
- Faciliter les inscriptions et les demandes d'investissement

## 🎯 OBJECTIFS DU SITE

1. **Engagement des Investisseurs** : Communiquer la proposition de valeur à la diaspora africaine
2. **Transparence** : Présenter clairement les produits d'investissement (Impact Fund, Growth Fund, Fixed Income)
3. **Conversion** : Convertir les visiteurs en investisseurs potentiels
4. **Informations** : Fournir des données sur les secteurs d'investissement et les retours attendus
5. **Confiance** : Montrer l'expertise de l'équipe de gestion et de gouvernance

- **Banneau Principal** : "Bridging the Gap Between Diaspora Capital & Ghana's Infrastructure Needs"

  - Impact social documenté

  - Sécurité du capital

- **Enregistrement et Certifications** :

  - TIN: C0066826144

#### 3. **Produits d'Investissement**
Trois sections dédiées :

**a) Impact Fund (Fonds d'Impact)**
- Type : Actions (parts) dans les projets identifiés au Ghana
- Cas d'usage : Investissements directs dans les secteurs clés
- Retours : Variable selon le projet
- Avantages : Impact social direct + retours financiers
- CTA : "Explorer les Projets"

**b) Growth Fund (Fonds de Croissance)**
- Type : Épargne Individuelle Périodique via Custodiam → Convertis en Fonds d'Investissement
- Cas d'usage : Investisseurs réguliers/flexibles
- Structure : Plans d'épargne mensuels/trimestriels
- CTA : "Créer un Plan d'Épargne"

**c) Fixed Income (Revenu Fixe)**
- Type : Épargne Individuelle avec Intérêts
- Cas d'usage : Investisseurs conservateurs
- Retours : Taux d'intérêt fixe garantis
- CTA : "Investir en Sécurité"

- **SSL/HTTPS** obligatoire

- **Audit de sécurité** régulier

### Performance
- **Temps de chargement** < 3 secondes
- **CDN** pour contenu global
- **Optimisation mobile** prioritaire

### Accessibilité
- **WCAG 2.1** Level AA minimum
- **Support multilingue** : Anglais, Français, Twi/Akan
- **Traducteur automatique** pour autres langues
